# Reference UI Forensics

## Source Material
The primary reference image provided is a 3-panel screenshot of a mobile-first precision agriculture application (e.g., John Deere Operations Center).

### Panel 1: Multi-Asset List (Home)
- **Layout**: List of interactive cards representing different fields/equipment.
- **Hierarchy**: Top-level progress bar -> Search/Filter -> Individual Assets.
- **Visuals**: Clean white cards, light gray background, green primary accents, status indicators (e.g., Active, Needs Attention).

### Panel 2: Satellite Map (Map)
- **Layout**: Full-screen geographic map view.
- **Hierarchy**: Floating search bar over map tiles.
- **Interaction**: Dropped pins representing specific hardware nodes. Tapping a pin drills down into asset details.

### Panel 3: Detailed Telemetry (Asset Detail)
- **Layout**: Focus on a single entity.
- **Hierarchy**: Header with asset name/status -> Primary KPI cards (Engine Load, Speed, Fuel) -> Secondary Metrics.
- **Visuals**: High-contrast typography, large numerical readouts, specific iconography for each metric type.

### Universal Paradigms
- **Bottom Navigation**: Persistent 4-tab bar (Home, Map, Plan, Analyze).
- **Typography**: Bold, highly legible sans-serif font suitable for outdoor glare.
- **Safe Areas**: Padding applied to ensure bottom nav does not obstruct core content.

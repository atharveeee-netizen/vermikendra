# Vermikendra Farmer Usability Test Script

## Context
This script must be executed with real farmers in the field using low-end Android devices in direct sunlight.

## Test Logistics
*   **Environment:** Outdoor, high glare, potentially dirty/wet hands.
*   **Device:** Mid/low-tier Android smartphone.
*   **Languages:** Hindi, Gujarati, English.

## Tasks
1.  **Check Bed Status:** "Can you tell me if Bed 01 is currently okay?"
2.  **Find Last Update:** "How long ago did the system check the bed?"
3.  **Voice Query:** "Tap the big green button and ask: 'What is the temperature of the bed?' in your native language."
4.  **Audio Comprehension:** "Did you understand the spoken answer?"
5.  **Offline State:** "I'm going to turn off your mobile data. How do you know the system is offline?"
6.  **Drill Down:** "Where would you tap to see more details about Moisture?"
